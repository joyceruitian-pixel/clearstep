# ClearStep Recording Demo Checklist

## Before recording

- Start the local server with the command in `NOTES.md`.
- Open `http://localhost:3000/` and the `slides/slides.html` file.
- Close unrelated tabs and hide private browser notifications.
- Confirm the browser is not showing an API key or private information.
- Have this assignment ready to paste:

  > Read pages 12–18 of your textbook. Write a one-paragraph response explaining the main character’s motivation. Include two pieces of evidence from the story and submit your response by Friday.

- Keep the presenter notes nearby, but speak naturally.

## Live demonstration plan (about 80 seconds)

1. Paste the prepared directions and click **Explain directions**.
2. Point out the one-sentence meaning and numbered steps.
3. Check one step to show the separate progress tracker.
4. Tap an underlined word such as **motivation** to show its simple definition.
5. Point to **Make it your level** and explain that the selected level changes the next AI explanation.
6. Scroll to **What to turn in** and show its separate checklist if it appears.
7. If there is time, open **Copy to Notes**, switch to Checklist or Complete homework plan, and show the preview.

## Backup plan

If the live AI request fails, do not fabricate a response or call a hardcoded response live. Stop the recording, save the real error state if useful, and record a separate short demo using a real successful AI response already saved in the browser. Say that it is a previously recorded real result if you edit the clips together.

## After recording

- Return to the slideshow for the AI, testing, safety, learning, and closing slides.
- Check that the final video is under four minutes.
- Make sure no personal information, API key, or unrelated browser content appears.
- Review the final video once with the sound on and once with the sound off for readability.
